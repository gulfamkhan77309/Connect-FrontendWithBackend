# Connecting Frontend with Backend

## 📚 What I Learned

I learned how to connect a frontend application with a backend server using APIs in the MERN stack.

### Key Concepts
- Connecting React with a Node.js and Express.js backend.
- Creating and handling REST API endpoints.
- Sending HTTP requests using `fetch()` or Axios.
- Handling JSON data between frontend and backend.
- Managing API responses and errors.
- Using environment variables to store API URLs.

### 🛠️ Technologies Used
- React.js
- Node.js
- Express.js
- REST APIs
- JavaScript

### 🎯 Learning Outcome
I gained practical knowledge of how the frontend communicates with the backend to send requests, receive data, and build full-stack web applications.
